# Core and Advanced Java Learning Flow

Here is a structured, sequential learning path for revising Core and Advanced Java based on the files in this directory. They are organized from fundamental concepts to more advanced topics.

### **Phase 1: Getting Started & Basics**
Start here to understand how Java works under the hood and get comfortable with basic syntax, variables, and operators.
1. `How_Java_Works.txt` (Theory)
2. `Hello.java` (Your first program)
3. `Naming.md` (Naming conventions in Java)
4. `Variables.java`
5. `Literals.java`
6. `Type_conversion_Casting.java`
7. `Arithmetic_Operators.java`
8. `Relational_Operators.java`
9. `Tricky_Relational_cases.java`
10. `Logical_Operators.java`
